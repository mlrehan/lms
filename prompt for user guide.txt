# Browser Automation Requirement

You MUST use browser automation.

For each role:

1. Login using the provided account.
2. Explore every available menu.
3. Open every accessible page.
4. Identify all available functions.
5. Capture real screenshots.
6. Record exact page names.
7. Record exact button names.
8. Record actual workflow steps.


DO NOT:

- Create fake screenshots
- Use placeholder images
- Use generated UI images
- Describe unavailable features


All screenshots must come from the real application.
